# Nima — Laboratory Companion (نیما)

اپلیکیشن آموزشی و کاربردی علوم آزمایشگاهی برای **وب، دسکتاپ و اندروید**.
طراحی الهام‌گرفته از سبک تمیز Agappe — **رابط کاربری کاملاً انگلیسی (چپ‌به‌راست)** و لوگوی «Nima» در صفحه اول؛
فقط توضیحات مختصر اخبار و مقالات **فارسی** است. (محتوای مرجع تست‌ها و تفسیر فرمول‌ها دوزبانه است: نام انگلیسی + توضیح فارسی.)

## 🚀 اجرا (سرور خودتان)

> پیش‌نیاز: **Node.js نسخه ۱۸ یا بالاتر** از [nodejs.org](https://nodejs.org) — همه دستورها با npm معمولی اجرا می‌شوند و به bun نیازی نیست.

```bash
# ۱) نصب وابستگی‌ها
npm install

# ۲) حالت توسعه (برای آزمایش سریع)
npm run dev          # یا: bun run dev   →  http://localhost:3000

# ۳) اجرای نهایی (production)
npm run build
npm start            # → http://localhost:3000  (در LAN با IP سیستم آزمایشگاه در دسترس است)
```

> نکته: برای اجرای دائمی روی سرور خودتان بهتر است production را با `pm2` یا سرویس systemd اجرا کنید.
> برای دسترسی از سایر دستگاه‌ها: `http://<IP-کامپیوتر-آزمایشگاه>:3000`

## 📲 تبدیل به اپلیکیشن — قدم به قدم

### راه ۱: نصب مستقیم به‌صورت اپ (PWA) — ساده‌ترین راه، بدون هیچ ابزار اضافه ⭐

**دسکتاپ (ویندوز):**
1. سرور را روشن کنید: `npm start`
2. در کروم یا اج آدرس `http://localhost:3000` را باز کنید
3. روی آیکن «Install app» (علامت + در انتهای نوار آدرس) کلیک کنید → **Install**
4. تمام! Nima پنجره مستقل می‌گیرد، در Start Menu آیکن می‌گذارد و حتی با خاموش بودن سرور آفلاین کار می‌کند

**اندروید:**
1. کامپیوتر و گوشی به یک وای‌فای وصل باشند
2. روی کامپیوتر IP را پیدا کنید: در CMD دستور `ipconfig` → خط **IPv4 Address** (مثلاً `192.168.1.10`)
3. سرور روشن باشد: `npm start` (اولین بار ویندوز فایروال را می‌پرسد → **Allow** بزنید)
4. در کروم گوشی آدرس `http://192.168.1.10:3000` را باز کنید
5. منوی ⋮ → **Add to Home screen** → Add
6. آیکن Nima روی صفحه گوشی می‌آید، تمام‌صفحه مثل اپ باز می‌شود و پس از اولین بازدید آفلاین هم کار می‌کند

### راه ۲: فایل APK واقعی اندروید (Capacitor) — اختیاری

پیش‌نیاز: [Android Studio](https://developer.android.com/studio) (شامل JDK)

1. در پوشه Nima:
   ```bash
   npm i -D @capacitor/cli
   npm i @capacitor/core @capacitor/android
   ```
2. فایل `capacitor.config.ts` در پروژه آماده است — فقط در خط `url` آدرس IP کامپیوتر خودتان را بگذارید
3. `npx cap add android`
4. `npx cap open android` (اندروید استودیو باز می‌شود)
5. برای اتصال http داخلی، در فایل `android/app/src/main/AndroidManifest.xml` داخل تگ `<application ...>` این خط را اضافه کنید:
   `android:usesCleartextTraffic="true"`
6. منوی **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
7. فایل ساخته‌شده: `android/app/build/outputs/apk/debug/app-debug.apk`
8. APK را به گوشی بفرستید و نصب کنید (Allow from this source)

> توجه: این APK به سرور روی کامپیوتر وصل می‌شود؛ اگر می‌خواهید گوشی کاملاً مستقل باشد، همان راه ۱ (PWA) آفلاین کامل دارد.

### راه ۳: نصب‌کننده ویندوز (Nima-Desktop.exe) — اختیاری

پوشه `electron/` در پروژه آماده است:

1. `cd electron`
2. `npm install`  (الکترون دانلود می‌شود، چند دقیقه)
3. اجرای آزمایشی: `npm start` — پنجره دسکتاپ Nima باز می‌شود (اگر سرور روشن نباشد خودش روشنش می‌کند)
4. ساخت exe: `npm run dist` → خروجی: `electron/dist/Nima-Desktop.exe`
5. فایل exe را هرج خواستید کپی کنید و کنارش فایل `nima-path.json` بگذارید (مسیر پوشه Nima خودتان):
   ```json
   { "nimaDir": "C:\\Nima" }
   ```
6. دابل‌کلیک روی `Nima-Desktop.exe` → برنامه باز می‌شود

### اجرای دائمی سرور (اختیاری — با pm2)

```bash
npm i -g pm2
pm2 start npm --name nima -- start
pm2 startup     # شروع خودکار پس از ری‌استارت سیستم
pm2 save
```

## 🔐 مدیر (Admin)

- رمز پیش‌فرض: `admin` (هش SHA-256 در localStorage ذخیره می‌شود).
- تغییر رمز: دکمه **Admin** → **Change admin password**.
- خروج مدیر: **Log out** (نشست تا بستن تب هم به‌طور خودکار تمام می‌شود).
- توجه: این احراز هویت سمت مرورگر است و برای جلوگیری از تغییر تصادفی محتوا طراحی شده، نه دفاع امنیتی در برابر مهاجم متخصص؛ سرور را در شبکه داخلی آزمایشگاه نگه دارید.

## 🗂 ساختار پروژه

```
src/app/            صفحه اصلی + API همگام‌سازی (news/articles از اینترنت)
src/components/nima/views/   home, tests, formulas, qc, integrity, accuracy, analyzer, articles, news, events, help
src/lib/integrity.ts         موتور روابط بین تست‌ها (۲۵ قانون) + نام‌های مستعار آنالیت‌ها
src/lib/checks.ts            وستگارد، سیگما، پرچم‌گذاری تک-تست
src/lib/auth.tsx             نقش مدیر (ورود/خروج/تغییر رمز)
src/lib/data/                بانک تست‌ها (۱۴ رشته)، فرمول‌ها، محدوده‌های مرجع
public/                      آیکون‌ها، فونت وزیرمتن، hero-lab.jpg، manifest، سرویس‌ورکر
scripts/                     اسکریپت‌های build/start (خروجی production با Node معمولی)
electron/                    پوسته دسکتاپ ویندوز (Nima-Desktop.exe با electron-builder)
capacitor.config.ts          تنظیمات آماده ساخت APK اندروید
```
